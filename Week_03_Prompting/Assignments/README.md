Experiment: ICIO, RTF, CO-STAR; GPT-6.1 Sol / Medium; 155 questions each.

- Task_1/report_sk.md: selection and justification; prompts.json and TXT templates.
- Task_2/report_sk.md: predictions, teacher validation, figures and timing limitations.

## Important limitations
All three prediction files contain identical SQL. Original reference IDs are inconsistent with the provided database; no labels or predictions were changed to conceal this. All exact scores are 43/155. Only end-to-end agent duration was measured; pure model inference time was unavailable. Full generation chat logs were not supplied. Reports explicitly discuss these limitations.

## Reproduce evaluation
Python standard library is sufficient:
```text
python Task_2/evaluate_all.py
python Task_3/reproduce_scores.py
cd Task_4
python paired_statistics.py --scores ICIO=../Task_3/scores_icio.json RTF=../Task_3/scores_rtf.json CO-STAR=../Task_3/scores_co_star.json --output statistics.json
```
Predictions are original outputs of the IDE agent, not generated by the evaluation scripts. Original instructor data and evaluator are preserved in Task_2/inputs. The minimally patched evaluator is separately provided.
